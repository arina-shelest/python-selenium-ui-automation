# python-selenium-ui-automation
Automated UI tests in Python using Selenium and Pytest.

## Tech Stack
* Python 3.13
* Selenium WebDriver
* Pytest

## How to run tests

1. Clone repo and create virtual environment:
```bash
git clone [https://github.com/arina-shelest/python-selenium-ui-automation.git](https://github.com/arina-shelest/python-selenium-ui-automation.git)
cd python-selenium-ui-automation
python3 -m venv .venv
source .venv/bin/activate
